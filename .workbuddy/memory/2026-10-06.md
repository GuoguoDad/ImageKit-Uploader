# 2026-10-06

## 修复设置面板「不能垂直滚动」+「右上角关闭按钮点击无反应」

### 现象
设置弹窗打开后内容超出屏幕，滚不动，底部的 Save / Cancel 点不到；右上角 ✕ 点击没反应。

### 根因（两个独立问题，都在 `styles/index.css` 的弹窗段）
1. **`.modal-backdrop` 用 `display: grid; place-items: center`**：隐式行是 auto 高度，
   子元素 `.modal` 的 `max-height: 100%` 在网格轨道固有尺寸阶段被当成 `auto`
   → 弹窗按内容高度撑开（实测 800 高窗口里弹窗 1123 高，`bottom = 1149`，溢出 349px），
   `.modal__body` 的 `overflow-y: auto` 失效（`scrollHeight === clientHeight === 991`）→ 永远滚不动。
2. **顶栏 `.app-header` 是 `-webkit-app-region: drag` 拖拽带（窗口用 `titleBarStyle: 'hiddenInset'`，高 64px）**：
   Electron 语义是 draggable 区域吞掉所有指针事件，与它重叠的元素即使 z-index 更高也收不到 click。
   弹窗标题栏落在 y 26~100，✕ 按钮实测 y 43~75、点击中心 y=59，正好落在 drag 带内
   （`.app-header__actions` 的 no-drag 框只覆盖到 y 47.5）→ 点 ✕ 被吞，表现为"没反应"。

### 修复
`src/renderer/src/styles/index.css`（唯一改动文件，+13 -2）
- `.modal-backdrop`：`display: grid; place-items: center` → `display: flex; align-items: center; justify-content: center`，
  并加 `-webkit-app-region: no-drag; app-region: no-drag;`（遮罩是 `fixed inset: 0`，等于整窗排除 drag 区）。
- `.modal__head` / `.modal__foot` 加 `flex: none`，防止被压缩。

### 验证（改前 / 改后实测，1160×800 窗口）
| 指标 | 改前 | 改后 |
| --- | --- | --- |
| 弹窗高度 / bottom | 1123 / 1149（溢出 349） | 748 / 774（余 26） |
| `.modal__body` clientHeight : scrollHeight | 991 : 991（滚不动） | 617 : 991（可滚，scrollTop 最大 375） |
| Save/Cancel 位置 | y 1103（屏幕外） | y 729（可见，且滚 body 时不动） |
| `.modal-backdrop` 计算值 | —— | `-webkit-app-region: no-drag` 已生效 |

最小窗口 940×620 也通过（弹窗 568、body 437/991 可滚）。
顺带回归了 `.modal--picker`（云端目录选择器）：小窗口下由 607 溢出变为 568 适配，
列表内部滚动正常（366/327）、底部操作条在视口内；大窗口（900 高）高度与改前一致（607），无视觉变化。
`npm run typecheck` 通过，`npm run build` 产物中两条声明都保留（未被 CSS 压缩丢掉）。
